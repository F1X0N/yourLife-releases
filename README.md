# Your Life · Releases

Instaladores públicos do **Your Life**. O código-fonte fica em um repositório privado; aqui ficam só os arquivos de cada versão, para baixar e para o próprio app se atualizar.

Cada versão em [Releases](../../releases) traz:

| Arquivo | Para quê |
| --- | --- |
| `your-life-vX.Y.Z-android-teste.apk` | Instalar no Android. Build de teste, não a versão da Play Store. |
| `your-life-vX.Y.Z-web.zip` | Prévia web estática. |
| `SHA256SUMS.txt` | Conferir a integridade dos arquivos. O app confere sozinho antes de instalar. |

**Instalar:** baixe o APK no celular, abra e permita "instalar apps de fontes desconhecidas". Depois da primeira instalação, as próximas versões aparecem dentro do app em Você › Atualizações, sem desinstalar e sem perder dados.

Os releases são publicados automaticamente pelo workflow de release do repositório do código. Não abra PRs aqui.
